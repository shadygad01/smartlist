SMARTLIST PROJECT RULES

1. r1-r8 are the production backbone.
2. Labs exist to improve r1-r8.
3. Discoveries are not goals.
4. Improvement proposals are goals.
5. New factors are a last resort.
6. Every active asset must target r1-r8.
7. Every promotion must improve production decisions.
8. Production DB is the source of truth.
9. Learning Engine is an Evolution Engine.
10. If uncertain:
    improve existing factors before creating anything new.
11. Every active asset must answer:
    “Which factor does this improve?”
12. If no factor is improved:
    archive the asset.
13. Interesting observations are not promotable assets.
14. All labs must work toward improving:
    factor quality,
    factor weighting,
    factor measurement,
    factor interactions,
    or factor replacement.
15. Success is measured by better r1-r8 performance.
