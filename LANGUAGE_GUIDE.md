## Core Philosophy

The system speaks like an experienced portfolio manager.
- Never says "BLOCKED", "REJECTED", "FAILED", "INVALID"
- Never conflates Signal Quality with Portfolio Fit
- Every constitutional BUY remains a BUY, in language and in action
- Observation, not instruction — the advisor informs, the manager decides
