═══════════════════════════════════════════════════════════════════════

1️⃣ No Duplicate Alerts

2️⃣ Background Processing
   └─ Scheduler runs in background thread

3️⃣ Safe Shutdown
   └─ Graceful shutdown with Ctrl+C
   └─ No data loss or errors

   └─ Daily scan: 08:30 Cairo Time

📝 Optional: Customize Timing
═══════════════════════════════════════════════════════════════════════

In the scheduler setup, change:

    # Current: 08:30 Cairo Time
    scheduler.add_job(daily_scan, CronTrigger(hour=8, minute=30, timezone=CAIRO))
    
    # To change time:
    scheduler.add_job(daily_scan, CronTrigger(hour=10, minute=15, timezone=CAIRO))
    
    # For monitoring interval:
    time.sleep(300)  # Change 300 seconds (5 min) to anything else

❓ Troubleshooting
═══════════════════════════════════════════════════════════════════════

Issue: "No module named 'apscheduler'"
  → Run: pip install apscheduler

Issue: Emails not sending
  → Check EMAIL_USER and EMAIL_PASS env vars
  → Gmail requires App Password (not regular password)

Issue: Telegram alerts not working
  → Verify TELEGRAM_TOKEN and TELEGRAM_CHAT_ID are correct
  → Check internet connection

Issue: Monitor runs but no alerts
  → Check if score actually reaches 35+
  → Check logs for any error messages
