# EGX SMC Scanner with Scheduler

## Features
✨ Daily scan at 08:30 AM Cairo Time
🚨 Real-time monitoring (every 5 min)
📧 Email alerts when score >= 35
📱 Telegram alerts when score >= 35

## Quick Start
```bash
pip install apscheduler
python main.py
```

## Environment Variables
- EMAIL_USER
- EMAIL_PASS  
- TELEGRAM_TOKEN
- TELEGRAM_CHAT_ID
