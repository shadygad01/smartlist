===============================================
TROUBLESHOOTING:
===============================================

Q: Workflow still times out?
A: Make sure you removed all APScheduler code
   Check that main() exits properly (not infinite loop)

Q: No emails being sent?
A: Check GitHub Secrets have EMAIL_USER and EMAIL_PASS
   Check GitHub Actions logs for errors
   Verify App Password (not regular Gmail password)

Q: Slow execution (> 3 minutes)?
A: Verify ThreadPoolExecutor with 6 workers is used
   Check parallel fetching is enabled
   Don't revert to sequential fetching

Q: No BUY alerts during market hours?
A: Check SMC logic in scan_stocks()
   Verify get_changed_stocks() correctly compares last_scores.json
   Test with Manual run to see all scores

Q: Files won't download?
A: Use these names: workflow.yml, main.py, requirements.txt, .gitignore
   Or copy-paste the content directly
