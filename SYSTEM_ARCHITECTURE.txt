         │
         ├─→ Run build_report()
         │
         ├─→ Check current_qualified = {stocks with score >= 35}
         │
         ├─→ new_alerts = current_qualified - last_alerted_stocks
         │

         │
         ├─→ send_alert_for_high_score(stock)
         │

         │
         └─→ Add to last_alerted_stocks (prevent duplicate)
         
    ✅ Alert sent, wait 5 minutes for next check

                    🔐 SAFETY MECHANISMS
                    
═══════════════════════════════════════════════════════════════════════════════

1. Duplicate Prevention:
   ├─ last_alerted_stocks set keeps track of alerted stocks
   └─ Only new stocks trigger alerts

2. Thread Safety:
   ├─ monitoring_active global flag
   └─ Graceful shutdown with Ctrl+C

3. Error Handling:
   ├─ Try-except blocks in monitor_scores()
   ├─ Fallback waits on error (sleep 60 sec)
   └─ Detailed error logging

4. Data Freshness:
   ├─ Only monitor during EGX trading days
   ├─ Check is_egx_trading_day()
   └─ Skip monitoring on holidays/weekends
