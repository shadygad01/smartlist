❌ COMMON ISSUES & SOLUTIONS
════════════════════════════════════════════════════════════════════════

Issue 1: "ModuleNotFoundError: No module named 'apscheduler'"
───────────────────────────────────────────────────────────────────────
❌ Error:
    Traceback (most recent call last):
    ...
    ModuleNotFoundError: No module named 'apscheduler'

✅ Solution:
    pip install apscheduler
    pip install --upgrade apscheduler
    
    Or with specific version:
    pip install apscheduler==3.10.4


Issue 2: "Email sending fails with 'SMTP error'"
───────────────────────────────────────────────────────────────────────
❌ Error:
    Email error: (535, b'5.7.8 Username and Password not accepted')

✅ Solution:
    1. Check EMAIL_USER is your Gmail address
    2. Use GMAIL APP PASSWORD, not your regular password
       └─ Go to: https://myaccount.google.com/apppasswords
       └─ Select Mail + Windows Computer
       └─ Copy generated password (16 characters with spaces)
    3. Try again with new password
    
    Example:
    EMAIL_PASS = "xxxx xxxx xxxx xxxx"  ← 16 chars with spaces


Issue 3: "Telegram message not received"
───────────────────────────────────────────────────────────────────────
❌ Error:
    Telegram: HTTP 401 — ...
    OR
    No message appears in Telegram chat

✅ Solution:
    1. Verify TELEGRAM_TOKEN is correct
       └─ Should be: 123456789:ABCdefGHIjklMNOPqrs
    2. Verify TELEGRAM_CHAT_ID is correct
       └─ Should be a long number (positive or negative)
    3. Bot must be added to chat with permissions
    4. Test with simple curl:
       
       curl -X POST https://api.telegram.org/bot{TOKEN}/sendMessage \
         -d chat_id={CHAT_ID} \
         -d text="Test message"


Issue 4: "No alerts sent when score reaches 35"
───────────────────────────────────────────────────────────────────────
❌ Problem:
    System runs but no alerts when score >= 35

✅ Troubleshoot:
    1. Verify score actually reaches 35+
       └─ Check build_report() output manually
    2. Check if monitoring thread is running
       └─ Add debug print in monitor_scores()
    3. Verify is_egx_trading_day() returns True
       └─ It might be weekend/holiday
    4. Check if stock is already in last_alerted_stocks
       └─ No duplicate alerts same day


Issue 5: "Scheduler doesn't run at 08:30"
───────────────────────────────────────────────────────────────────────
❌ Problem:
    daily_scan() never executes at scheduled time

✅ Solution:
    1. Check system timezone is correct
    2. Verify CAIRO timezone is set to "Africa/Cairo"
    3. Check no exceptions in console
    4. Add debug in daily_scan():
       
       ```python
       def daily_scan():
           print(f"🟢 daily_scan triggered at {fmt_cairo()}")
           ...
       ```
    5. Wait for actual 08:30 (apscheduler won't trigger if past)


Issue 6: "Out of memory after running 24 hours"
───────────────────────────────────────────────────────────────────────
❌ Problem:
    Program slows down or crashes after long run

✅ Solution:
    1. Clear last_score_data periodically:
       
       ```python
       # In monitor_scores, after 24 hours:
       if iteration % (24 * 60 * 5) == 0:  # Every 24 hours
           last_score_data = {}
       ```
    2. Restart program daily
    3. Use system task scheduler for auto-restart
