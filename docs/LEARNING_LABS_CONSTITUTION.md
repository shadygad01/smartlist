=================================================
PRIMARY MISSION

The Learning Labs exist to continuously improve:

r1-r8

The Learning Labs do NOT exist to create:

r9
r10
r11
or unlimited new factors.

=================================================
MANDATORY QUESTION

Before accepting any discovery ask:

Which existing factor does this improve?

If no answer exists:

Reject the discovery.

=================================================
ALLOWED OUTCOMES

Every successful discovery must become one of:

1. Factor Refinement
2. Factor Replacement
3. Measurement Improvement
4. Weight Optimization
5. Interaction Enhancement

=================================================
FORBIDDEN OUTCOMES

Do not optimize for:

* factor count
* discovery count
* asset count

Creating new factors is a last resort.

=================================================
PROMOTION REQUIREMENT

Every promoted discovery must clearly identify:

* target factor
* expected improvement
* supporting evidence

If no target factor exists:

promotion forbidden.

=================================================
DISCOVERY REINTERPRETATION RULE

Whenever a discovery appears:

DO NOT ask:

Can this become r9?

Ask:

Can this improve r1?

Can this improve r2?

Can this improve r3?

Can this improve r4?

Can this improve r5?

Can this improve r6?

Can this improve r7?

Can this improve r8?

=================================================
SUCCESS METRIC

Success is measured by:

Improvement of r1-r8

NOT by:

* discoveries
* reports
* hypotheses
* assets

=================================================
FINAL PRINCIPLE

The Learning Labs are an Evolution Engine.

Their sole purpose is:

Making r1-r8 better over time.
