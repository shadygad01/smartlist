§9 — Final Conclusions

Q1. What assumptions are still protected from research?

  • A01: Price below EQ (cur < eq)
  • A03: EQ = 50% Fibonacci level
  • A14: Swing detection lookback = 60 bars

Q2. What profitable opportunities are currently being rejected?

4097 discount-zone days were NOT signaled by the scanner. Of these, 1653 (40%) were winners (>5%). Rejected candidates: avg r20d=3.4%, vs accepted avg=4.5%. Buy-zone rejected: avg=4.6%. Key insight: scanner adds significant value — accepted outperforms rejected. PRIMARY BLIND SPOT: score 35-44 signals never stored in DB.

Q3. Which filters HURT performance?

  • None confirmed at p<0.10

Q4. Which filters deserve HIGHER weight?

  • Sweep Detected: +0.015

Q5. Which filters deserve LOWER weight?

  • Order Block (r2>0 hurts -1.6%)

Q6. Which filters should be REMOVED entirely?

  • r2_ob (Order Block) — data shows OB reduces return by -1.6%, confirmed

Q7. Is the current score architecture optimal?

Current additive weighted sum has OOS R²=-0.15 (negative!). Architecture is not predicting returns. Recommendation: mandatory gate (sweep=1 + r1≥gate) × quality bonus. Non-linear with minimum viable conditions outperforms additive sum.

Q8. What is the single highest-impact improvement available today?

Fix HTF scoring inversion: HH+HL currently scores highest but returns -0.8%. HL-only returns +11.6%. A single logic fix (swap full/partial scoring) could shift system performance significantly.

Q9. System Status Summary

The scanner identifies real opportunities (mean r20d=+4.6%, PF=2.64). However 3 scoring components are backwards (OB, HTF, Demand). Fixing these 3 components alone could meaningfully improve expectancy without changing signal count. Opportunity flow is healthy at 639 signals.
