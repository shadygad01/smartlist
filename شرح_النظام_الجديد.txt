   ├─ يرسل تقرير شامل
   └─ مع رسالة Telegram للـ stocks وصلت 35+

2️⃣ **مراقبة فورية 24/7 (كل 5 دقائق)**
   ├─ يفحص الـ scores باستمرار
   ├─ عندما يصل أي stock إلى 35+
   └─ يرسل Email + Telegram **فوراً** (بدون انتظار الساعة 8:30)

🔧 التثبيت والتشغيل
═══════════════════════════════════════════════════════════════════════

**الخطوة 1: تثبيت المكتبة:**
    pip install apscheduler

**الخطوة 2: استخدام الملف الجديد:**
    استبدل main.py بـ main_with_scheduler.py

**الخطوة 3: التشغيل:**
    python main_with_scheduler.py

✓ البرنامج سيبقى يعمل في الخلفية
✓ اترك الـ terminal مفتوح
✓ اضغط Ctrl+C للإيقاف الآمن

⚙️ متغيرات البيئة المطلوبة
═══════════════════════════════════════════════════════════════════════

قبل التشغيل، تأكد من تعريف هذه المتغيرات:

    EMAIL_USER=your_email@gmail.com
    EMAIL_PASS=your_gmail_app_password  ← App Password وليس password عادي
    TELEGRAM_TOKEN=your_bot_token
    TELEGRAM_CHAT_ID=your_chat_id

مثال (في Windows):
    set EMAIL_USER=shady.gad@live.com
    set EMAIL_PASS=xxxx xxxx xxxx xxxx
    set TELEGRAM_TOKEN=123456789:ABCDEFGhijklmnop
    set TELEGRAM_CHAT_ID=987654321

مثال (في Linux/Mac):
    export EMAIL_USER=shady.gad@live.com
    export EMAIL_PASS="xxxx xxxx xxxx xxxx"
    export TELEGRAM_TOKEN="123456789:ABCDEFGhijklmnop"
    export TELEGRAM_CHAT_ID="987654321"

📝 تخصيص الأوقات (اختياري)
═══════════════════════════════════════════════════════════════════════

غير وقت المسح اليومي:
    
    # الحالي: 8:30 صباحاً
    scheduler.add_job(daily_scan, CronTrigger(hour=8, minute=30, timezone=CAIRO))
    
    # لتغيير الوقت (مثلاً 10:15):
    scheduler.add_job(daily_scan, CronTrigger(hour=10, minute=15, timezone=CAIRO))

غير فترة المراقبة:
    
    # الحالي: 300 ثانية = 5 دقائق
    time.sleep(300)
    
    # للمراقبة كل دقيقة واحدة (أسرع):
    time.sleep(60)
    
    # للمراقبة كل 10 دقائق (أبطأ):
    time.sleep(600)

🔍 الدوال المضافة الجديدة
═══════════════════════════════════════════════════════════════════════

1. send_alert_for_high_score(stock, score, result)
   └─ ترسل تنبيه فوري عند وصول score إلى 35+

2. monitor_scores()
   └─ تراقب الـ scores بشكل مستمر
   └─ تعمل في thread منفصل

3. daily_scan()
   └─ المسح اليومي في وقت محدد

4. manual_scan()
   └─ مسح يدوي عند الطلب (إضافي للمستقبل)

✅ تحقق من:
    1. الفعل score يصل إلى 35+
